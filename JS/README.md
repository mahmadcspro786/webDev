# Personal Finance Manager

## About
A simple JavaScript project that helps manage income and expenses using Node.js.

## Features
• Add income and expenses  
• Calculate total income and expenses  
• Check remaining balance  
• Search and filter transactions  

## Technologies
• JavaScript  
• Node.js  
• Git and GitHub  

## How to Run
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `node index.js`.

## Learning Goals
This project is built to practice JavaScript fundamentals, including variables, functions, arrays, objects, operators, and array methods.
